# Engineering feature coverage

The MCP server has 51 tools. Five fixed extension tools provide discovery/read/preview/apply/reload while workers change independently of the host; see [extensions](EXTENSIONS.md). Comfort/classic V15.1 is the primary profile; Unified follows with version limits. See [validation status](NATIVE-ACCEPTANCE.md) for native boundaries and [API compatibility](API-COMPATIBILITY.md) for the V15.1–V19 build checks and V20/V21 limits. PLC and Unified native writes require separate acceptance. Build/offline checks do not establish every native operation or exact V15.0 compatibility. The WinForms UI supports classic HMI workflows plus API-supported Unified and offline PLC native transfers; see [desktop usage](https://github.com/votecoffee/SiemensMCPServer/blob/main/docs/DESKTOP.md).

PLC tools add discovery, offline object/property/group operations, block/type/tag-table native XML reads/import/export, dependency-ordered bundles, reviewed SCL/STL generation and compile diagnostics. Only a verified native Offline state permits PLC export/mutation. Supported software roots exclude hardware, technology objects, watch/force tables and online services. Protected blocks may provide only public interfaces; generic imports/generation do not assert source-content equality. Source generation keeps a new external source and may replace declared blocks; its preview makes that scope explicit.

PLC [inspection extensions](PLC-INSPECTION.md) add native readable SCL/STL/DB/UDT export, literal source search and bounded native cross-references. V15.1–V19 expose source export; cross-reference service types are present in inspected V18/V19 and absent in V15.1/V16/V17. Both captures require verified Offline state. LAD/FBD source conversion is not synthesized. Native project acceptance remains pending.

Mutations use expiring single-attempt previews, candidate hashes, explicit target identity, native exclusive access and transactions. Scalar edits verify authored returned fields, allowing known computed PLC modification/compile metadata to update. Generic imports retain before/after evidence with content equality not asserted. Compile runs outside an edit transaction. Save and runtime behavior are separate results.
